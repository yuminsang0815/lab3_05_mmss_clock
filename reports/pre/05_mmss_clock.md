# 실험 전 레포트: MM:SS 시계 및 동적 디스플레이

작성일 2026-09-25.

## 1. 동작 원리와 핵심 파라미터 계산

### 동작 원리
온보드 50 MHz 메인 클록을 분주하여 1초 주기마다 활성화되는 clock-enable 신호를 생성하고, 이를 통해 00:00부터 59:59까지 총 3,600초를 계수하는 4자리 BCD 시계 회로를 구성한다. 
초 1의 자리(0~9), 초 10의 자리(0~5), 분 1의 자리(0~9), 분 10의 자리(0~5)로 구성된 다단 BCD 카운터는 59초에서 60초가 될 때 분 1의 자리를 1 증가시키고, 59분 59초에서 다음 1초가 경과하면 00:00으로 롤오버(Wrap-around) 순환한다.
4자리의 시간 데이터는 4 kHz의 고속 스캔 클록(자리당 1 kHz)을 통해 시분할 다중화(Time-division Multiplexing) 방식으로 7세그먼트 FND에 순차 표출되며, 잔상 효과(POV)에 의해 4자리가 동시에 켜져 있는 것처럼 표시된다. 분과 초의 시각적 구분을 위해 분 1의 자리 점등 슬롯에서 소수점 점(dp)을 강제 활성화한다.

### 핵심 파라미터 계산
1. **1초 기준 분주 카운트 (`CLK_HZ`)**:
   - 입력 주 클록 주파수 $f_{\mathrm{clk}} = 50\text{ MHz} = 50,000,000\text{ Hz}$
   - 1초 시간 간격 $T_{\mathrm{sec}} = 1.0\text{ s}$
   - 1초 생성을 위한 카운터 주기 수:
     $$\text{COUNT\_CYCLES} = 50,000,000\text{ cycles}$$
   - 카운터 레지스터 비트 폭:
     $$\text{COUNT\_WIDTH} = \lceil\log_2(50,000,000)\rceil = 26\text{ bits}$$
($2^{25} = 33,554,432 < 50,000,000 \le 2^{26} = 67,108,864$)
   - `subsecond` 카운터가 0부터 $49,999,999$까지 계수한 후 0으로 리셋될 때 1초 자리올림이 발생한다.

2. **동적 스캔 분주 파라미터 (`SCAN_CYCLES`)**:
   - 디스플레이 스캔 목표 주파수 $f_{\mathrm{scan}} = 4,000\text{ Hz}$ (4자리 전체 1주기 순회 주파수는 $1,000\text{ Hz}$)
   - 1자리 전환당 필요한 클록 수:
     $$\text{SCAN\_CYCLES} = \frac{f_{\mathrm{clk}}}{f_{\mathrm{scan}}} = \frac{50,000,000}{4,000} = 12,500\text{ cycles}$$
   - 스캔 카운터 비트 폭:
     $$\text{SCAN\_WIDTH} = \lceil\log_2(12,500)\rceil = 14\text{ bits}$$

3. **테스트벤치 가속 축소 파라미터**:
   - 3,600초 전체 검증 시간을 현실적으로 단축하기 위해 `CLK_HZ = 2`로 설정한다.
   - 시뮬레이션에서는 1초가 2클록(40 ns)으로 모델링되므로, 3,600초 순환 검증을 수 밀리초 이내에 빠르게 완료할 수 있다.

## 3. 테스트벤치 자극과 기대 결과

시뮬레이션 환경에서는 `CLK_HZ=2` (1초 = 2클록 = 40 ns)로 축소 인가하며, 주요 롤오버 경계 시점에서 시간 레지스터 `{mt, mo, st, so}`를 검사한다.

| 검사 순서 | 검사 항목 및 인가 자극 | 기대 시간/출력 | 판정 기준 및 검증 의미 |
|:---:|---|:---:|---|
| Check 1 | 디코더 digit 0 입력 | `8'b1111_1100` | 세그먼트 '0' 패턴 정상 디코딩 검증 |
| Check 2 | 디코더 digit 9 입력 | `8'b1111_0110` | 세그먼트 '9' 패턴 정상 디코딩 검증 |
| Check 3 | 리셋 해제 직후 초기 상태 | `00:00` | 카운터 4자리 0 초기화 검증 |
| Check 4 | 10초 경과 (`advance(10)`) | `00:10` | 초 1의 자리 9에서 10의 자리로 자리올림(00:09 $\rightarrow$ 00:10) 검증 |
| Check 5 | 50초 추가 경과 (`advance(50)`) | `01:00` | 초 59초에서 분 1의 자리로 60진 자리올림(00:59 $\rightarrow$ 01:00) 검증 |
| Check 6 | 3,539초 추가 경과 (`advance(3539)`) | `59:59` | 3599초 도달 시 최댓값 표출 검증 |
| Check 7 | 1초 추가 경과 (`advance(1)`) | `00:00` | 3600초 시점에서 00:00으로 오버플로 순환(Wrap-around) 검증 |

## 4. 시뮬레이션 결과 및 수정 실험

### 정상 시뮬레이션 확인
- **종료 로그**: `LAB3_MMSS_PASS checks=7`, 종료 시각 `144031000 ps (144031 ns)`
- **파형 분석**:
  - `advance(10)` 후 `st`가 1로 올라가며 `00:10` 형성 확인.
  - `advance(50)` 후 `st`와 `so`가 0으로 리셋되고 `mo`가 1로 올라가며 `01:00` 형성 확인.
  - 144,000 ns 부근에서 `59:59`에서 정확히 1초(2클록) 뒤 `00:00`으로 일괄 롤오버됨을 확인.

### 수정 실험 (오류 주입 및 복구)
테스트벤치의 `mmss_counter` 인스턴스에 전달하는 `CLK_HZ`를 2에서 4로 변경하여 자리올림 간격을 2배 지연시켰을 때 불일치 검출 동작을 점검한다.

| 실험 단계 | 설정 내용 | 기대 동작 | 실제 실행 결과 | 비고 |
|---|---|---|---|---|
| 정상 실행 | `CLK_HZ = 2` | 2클록당 1초 계수 | `LAB3_MMSS_PASS checks=7` (144031 ns 종료) | 정상 통과 |
| 고장 주입 | `CLK_HZ = 4` 로 변경 | 4클록당 1초 계수 (진행 속도 1/2 지연) | `advance(10)` 시점에 기대값 `00:10` 대신 `00:05`가 읽혀 `$fatal` 중단 | 자리올림 타이밍 검증 신뢰성 확인 |
| 원복 복구 | `CLK_HZ = 2` 복원 | 2클록당 1초 계수 복원 | `LAB3_MMSS_PASS checks=7` 복구 | 정상 확인 |

## 5. 보드 실험 계획 및 관찰 항목

### 하드웨어 환경 및 핀 매핑
- **타깃 FPGA**: Spartan-7 `xc7s75fgga484-1`
- **클록 및 리셋**: 온보드 50 MHz 클록 (B6 핀), 리셋 푸시버튼 K4
- **7세그먼트 출력 핀**: 데이터 8핀(`seg_data[7:0]`: H2, J7, J3, J1, E4, E2, F5, F1), 자리 선택 8핀(`seg_com[7:0]`: K5, K3, K1, L6, G3, G1, H6, H4)

### 보드 관찰 절차
1. 비트스트림(`lab3_mmss_clock.bit`) 다운로드 후 K4 버튼으로 리셋 초기화를 수행하여 4개 자리에 `00:00`이 표시되는지 확인한다.
2. 초 1의 자리가 1초 간격으로 정확히 1씩 증가하는지 확인한다.
3. 9초에서 10초로 넘어갈 때 초 10의 자리가 1로 바뀌는지, 59초에서 1분 00초로 넘어갈 때 분 1의 자리가 1로 바뀌는지 관찰한다.
4. 분과 초 사이의 구분점(분 1의 자리 FND의 우하단 점 dp)이 상시 켜져 있어 분과 초가 명확히 구분되는지 확인한다.
5. 4 kHz 스캔 동작으로 인해 눈으로 볼 때 깜빡임(Flicker) 없이 4자리가 선명하고 안정적으로 유지되는지 확인하고 사진 및 영상으로 기록한다.
